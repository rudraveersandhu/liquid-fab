# liquid_fab example

Presets and a live playground for [`liquid_fab`](../README.md).

```bash
flutter run -d chrome
```

To regenerate the README's GIF and screenshot from these widgets (needs
`ffmpeg`):

```bash
./tool/make_readme_media.sh
```

To rebuild the live demo and publish it to the `gh-pages` branch:

```bash
./tool/deploy_demo.sh
```
